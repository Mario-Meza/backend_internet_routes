## Run as network

### Correr aplicacion en red
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### Iniciar fastapi en red
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### Iniciar conexión de red en telefono
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
